Question 1 — sets and functions

W01-Q01-PA (M1)

Method and conditions. List the two subsets of the stated universal set Ω\Omega, then apply the definitions of intersection, union, complement and subset.

We have

A={2,4,6,8,10,12},B={1,2,3,4,6,12}. \begin{aligned} A&=\{2,4,6,8,10,12\},\\ B&=\{1,2,3,4,6,12\}. \end{aligned}

It follows that

A∩B={2,4,6,12},A∪B={1,2,3,4,6,8,10,12},Ac={1,3,5,7,9,11}. \begin{aligned} A\cap B&=\{2,4,6,12\},\\ A\cup B&=\{1,2,3,4,6,8,10,12\},\\ A^c&=\{1,3,5,7,9,11\}. \end{aligned}

The statement B⊆AB\subseteq A is false. For example, 1∈B1\in B but 1∉A1\notin A.

Marks (5). Intersection 1; union 1; complement 1; correct subset decision 1; valid counterexample 1.

Common mistakes. Confusing union with intersection; taking the complement relative to a set other than Ω\Omega; giving a conclusion about the subset relation without a counterexample.

W01-Q01-PB (M1)

Method and conditions. Test injectivity and surjectivity against the stated domain/codomain, then distinguish implication from equivalence and use an odd-square contradiction for the reverse implication.

Every input having exactly one output makes ff a function. Injectivity instead requires distinct inputs to have distinct outputs. Here,

f(−2)=f(2)=4andf(−1)=f(1)=1, f(-2)=f(2)=4\quad\text{and}\quad f(-1)=f(1)=1,

so ff is not injective. Its range is {0,1,4}\{0,1,4\}, which equals the stated codomain. Therefore ff is surjective.

The parity relation is P⇔QP\Leftrightarrow Q. If n=2kn=2k, then n2=4k2n^2=4k^2, so P⇒QP\Rightarrow Q. Conversely, suppose n2n^2 is even but nn is odd. Then n=2k+1n=2k+1, so

n2=4k2+4k+1, n^2=4k^2+4k+1,

which is odd, a contradiction. Thus Q⇒PQ\Rightarrow P.

Marks (4). Valid collision and non-injectivity conclusion, 1; range and surjectivity conclusion, 1; correct equivalence relation, 1; valid contradiction for Q⇒PQ\Rightarrow P, 1.

Common mistakes. Treating “one output per input” as injectivity; checking surjectivity without the stated codomain; giving only P⇒QP\Rightarrow Q; assuming the reverse implication without justification.

W01-Q02-PB (M1, M2)

Method and conditions. Prove the identity for all integers n≥1n\ge1 by establishing a base case and the implication from nn to n+1n+1.

For n=1n=1, the left-hand side is 3(1)−1=23(1)-1=2, while the right-hand side is 1(3+1)/2=21(3+1)/2=2. The base case holds.

Assume for some n≥1n\ge1 that

∑k=1n(3k−1)=n(3n+1)2. \sum_{k=1}^{n}(3k-1)=\frac{n(3n+1)}{2}.

Then

∑k=1n+1(3k−1)=∑k=1n(3k−1)+3(n+1)−1=n(3n+1)2+3n+2=3n2+7n+42=(n+1)(3n+4)2=(n+1)(3(n+1)+1)2. \begin{aligned} \sum_{k=1}^{n+1}(3k-1) &=\sum_{k=1}^{n}(3k-1)+3(n+1)-1\\ &=\frac{n(3n+1)}{2}+3n+2\\ &=\frac{3n^2+7n+4}{2}\\ &=\frac{(n+1)(3n+4)}{2}\\ &=\frac{(n+1)(3(n+1)+1)}{2}. \end{aligned}

Question 3 — logarithms and a declining benefit stream

W01-Q03-PA (M2)

Method and conditions. State the positivity conditions for the logarithm arguments, combine the logarithms, and retain only admissible roots.

The domain requires x−1>0x-1>0 and x+2>0x+2>0, so x>1x>1. On this domain,

log⁡((x−1)(x+2))=log⁡18. \log\bigl((x-1)(x+2)\bigr)=\log18.

Because log\log is injective on its positive domain,

(x−1)(x+2)=18, (x-1)(x+2)=18,

and hence

x2+x−20=0=(x−4)(x+5). x^2+x-20=0=(x-4)(x+5).

The candidates are x=4x=4 and x=−5x=-5. Only x=4x=4 satisfies x>1x>1, so the solution is x=4x=4.

Common mistakes. Manipulating logarithms before enforcing positivity; writing a sum rather than a product inside the logarithm; keeping the inadmissible root.

Solution to W01-ST01-PA (M1)

Method. Distinguish the definition of a function from the definitions of injectivity and surjectivity, using the stated domain and codomain.

Every input has exactly one output, so the rule defines a function. It is not injective because

f(−1)=f(1)=1 f(-1)=f(1)=1

{f(−1),f(0),f(1),f(2)}={0,1,4}, \{f(-1),f(0),f(1),f(2)\}=\{0,1,4\},

which equals the stated codomain. Therefore ff is surjective.

Marks (5). Function/injectivity distinction, 1; valid collision, 1; correct non-injectivity conclusion, 1; output-set check, 1; correct surjectivity conclusion, 1.

Common mistakes. Calling every function injective; checking only adjacent inputs; ignoring the stated codomain when testing surjectivity.
